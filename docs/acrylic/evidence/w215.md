**`label_regression.py` 的一条假阳性,单独说明**:`--schema income_statement --schema debt_maturity
--baseline d652d10` 报 `totals: identical=929 changed=8`(duni/enea/medcap/nobia/rejlers/rusta 六家的
`due_within_1_year` / `due_1_to_5_years`,全部方向是 `False→True`)。查证过程:

1. 该脚本的 `syns()` helper 对 "baseline" 一侧**硬编码**用 `{s.lower()}` 构造同义词集(见脚本自己的
   docstring:"the baseline builds it verbatim"),不管 `--baseline` 传的是哪个 ref,从不调用
   `old._clean_label`。
2. 而生产代码的真实调用点(`extract.py` 里 `own_syns = {cl for s in sf.get("synonyms",[]) if
   (cl := _clean_label(s))}`)在 `d652d10` 和 `dfce54f` 两版里逐字节相同(`diff` 输出为空,`_clean_label`
   / `_label_known` 函数体也逐字节相同)。
3. 用 `replay_check` 交叉验证:这六家在 `debt_maturity` 的 replay 结果全部是 `same`(confidence/
   evidence/checks/warnings 逐项相同)。

结论:这是脚本本身"假定 baseline 用 verbatim 匹配"的固定方法论产物,对任何一个已经带 `_clean_label`
的近期 baseline(而不是脚本文档设想的、引入 `_clean_label` 之前的老 `origin/acrylic`)都会报出同样的
假阳性,与这次重构无关,不是回归。
