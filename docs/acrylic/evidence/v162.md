## Route change

`PAGE_SELECT_HINTS=retry` keeps run 1 on the ordinary v146-b prompt. After majority's exact
stored-answer trigger has had a chance to skip the work, run 2 receives the page markers only if
run 1's first `identity` check did not pass or any schema field is null. A hinted second run writes
`"hints": "run2"` into the merge record. `PAGE_SELECT_HINTS=1` and an unset flag keep their prior
behaviour.

The retry decision is an invocation-level context parameter, not a mutable process environment:
the same request can make its first selection unhinted and its second selection hinted. The route
stubs cover a failed identity check, a passed check with a null schema field, and the pre-existing
majority exact-match skip; the selection test proves the parameter overrides an ambient `=1` only
for that call.

## Measurement

Configuration was Codex `gpt-5.6-terra`, carrying basis, `EXTRACT_TWO_PASS=1`,
`EXTRACT_MERGE_RUNS=majority`, and `PAGE_SELECT_HINTS=retry`. There was one successful `/extract`
request per company and no client resends or provider errors.

- 23 routes completed; 32 Codex extraction runs (within the 50-run budget).
- 14 exact stored matches skipped run 2.
- 8 routes triggered marked run 2: `bergman_beving_2025`, `bioinvent_international_2025`, `cavotec_2025`, `fm_mattsson_2025`, `hansa_biopharma_2025`, `modern_times_2025`, `momentum_2025`, `ratos_2025`.
- One additional majority-required run 2 (`net_insight_2025`) was unhinted because its first run
  passed the identity check with no null field but did not exactly match stored. Raw evidence: all
  23 `run1` records plus the 9 actual `run2` records are below this report. External `run1-kb`
  and `merged-kb` each contain 23 copies; `run2-kb` contains the 9 actual
  second-run copies.

The 55 in-scope value labels were 19/55 correct in the stored baseline. Fresh run 1 was 15/55,
marked run 2 was 7/21 on the routes that actually ran it, and the merged output was 17/55.
Cited-label pages were 16/51 before and 16/51 merged. The two merged value regressions are
`cavotec_2025.total_debt` and `fm_mattsson_2025.total_debt`; no merged improvement offsets them.
This is evidence against enabling retry by default.

The strict release rule preserves every already-correct value and cited page, then requires at least
one additional correct value. It permits **run 1** for `hansa_biopharma_2025` (within-one-year
becomes right) and `momentum_2025` (total debt becomes right). Those two copies project 21/55
values and 18/51 pages for this target set; all other 21 records stay stored. No `data/` record is
published by this lane.

## Decision

**Keep `PAGE_SELECT_HINTS` off by default.** Retry improved neither the merged target ledger
(19/55 to 17/55) nor its cited-page count. It remains an explicit experiment flag; the default-off
replay is deterministic and unchanged. Publish only the two external run-1 candidates listed above,
not the merged records.
