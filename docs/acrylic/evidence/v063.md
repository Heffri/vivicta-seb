## Gap counting (per type, this seed alone; extract-layer items named for the supervisor)

1. **Total row not printed** (Enea): the note prints two subtotals (`Total non-current/current
   liabilities, interest-bearing`); 305,555 never appears as one row. Needs a sum-of-subtotals
   statement-fill for total_debt — extract-layer; adding a subtotal synonym would have produced a
   *wrong* total (169,152), which is why schema was not touched here.
2. **Date-per-instrument maturity** (Proact): the carrying note gives each instrument's maturity
   *date* (`16 Jul 2026 → 216,360`, `2026 → 96,098`, `2027–2030 → 166,153`); the model's 312,458 for
   w1y was **correct** (216,360 + 96,098, and 312,458 + 166,153 = 478,611 exactly) and was corrected
   away to 0 by the column guard ("another segment's column; rows read from column 1 of 3"). No
   mechanism reads date-shaped maturities. Extract-layer, ×1, cost: a would-be full-confidence
   company (identity closes exactly).
3. **Carrying + buckets + cash-flow total on one 6-number row** (VBG): `_row_amounts(row, 4)` returns
   6, count guard declines, model declines too — a carrying-vs-contractual-aware column reader would
   also have to decide which total the buckets sum to (1,712,314 vs the 1,504,774 carrying). The
   schema identity would then honestly fail (undiscounted buckets vs carrying total, the documented
   Boozt tension) while the fields gain values. Extract-layer, ×1.
4. **Wrong table: net-debt movement rows** (Scandi Standard): v051's FM Mattsson shape again; the
   real maturity note never reaches candidacy among [127,128,134,148,102]. Locator-territory, ×1.
5. **Lease-only debt + movement-row contamination** (BioInvent): total from the lease note is
   defensible (only interest-bearing debt), but pass 2's −1,049 is a remeasurement/movement row and
   the two passes disagree structurally. Model variance + boundary case, ×1.
6. **Interest-renegotiation table as the only bucket source** (Duni): `more than one year` wording
   attested unsafe (see above), so no schema lever exists; the honest read is 1–5y = 1,498 from the
   loans' own terms (p.182: terms to March/May 2027), which no current mechanism infers from prose.
   ×1.
7. **Bucket-column over-valve blind without a total column** (Net Insight pass 1): a prior-year
   `Total 81,489 57,647` row was written into buckets (81489 → w1y!) because the derived reading
   carried no total column for the `over` check to compare against. One more guard input
   (reject bucket reads whose row label is itself a Total variant) — extract-layer, ×1. Pass 1 was
   0.5-junk before the write, so no stored value regressed — but the shape is a live wrong-write
   path.
8. **Model pass-to-pass variance**: 4/10 companies changed pages or rows between identical calls
   (Net Insight, CellaVision, Synsam, BioInvent); in 3 of the 4 the *better* pass was dramatically
   better (1.0-check-passed vs 0.5-failed). The two-pass-per-company protocol is the only thing
   standing between this seed and a 0-full-confidence round — CellaVision's only full read is pass 1.
