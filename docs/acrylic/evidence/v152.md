Lane `ao/vivicta-glm-88/v152-hints-ab-broad`, off `origin/acrylic` `c846030` (dispatch baseline; the
v146-b gate commit). **This lane changes no code and no data**: the branch carries this evidence file
and the 40 route records under `v152/`; `data/` was restored to `HEAD` after the runs (verified clean).
Why this round: v146's page-select hints (candidate-page markers + the carrying-versus-liquidity
sentence, default **off**) were measured only on hard companies with an isolated KB. A default flip

rule: B ≥ A on the ✓ group **and** B > A on the hard group → recommend default on; B < A on the ✓
group → default off, stating where it loses.

## B 相对 A:变好/变差名单与原因

- **变好:** viscaria (+1 — B's window moved onto the tagged carrying note p.110 and w1y 661.8 got
  read; A sat on the undiscounted pair [100,101] and lost the same field), hexatronic (+2 — same
  window as A, but B answered the two v150 M-select values 62 and 2,181 where A left them null).
- **变差:** rusta (−4 — identical window [115,116]; B returned null on all four fields where A read
  the lease maturity table through three column repairs; the only debt in the report is lease
  liabilities, the page is untagged, and the hint names targets the report does not have),
  inwido (−1 — identical window; B read 1,801.5 instead of 1,796.0), fm_mattsson (−1 — B's window
  moved onto the tagged, correct note p.141 and then read "column 1 of 4" = the year 2025 as
  total_debt; A's off-label window still read one field), alligo (−1 — B's window moved onto the
  tagged BS p.143 but w1y 473 was not read there; A's window [141,142] read both fields from the
  loan note).
- **Selections moved without value effect:** enity (B onto the tagged BS p.54; value null ✓ either
  way), flerie (A kept the note, B took the tagged BS p.57; both 0/2), vef (B left the label page
  for the tagged carrying note p.21; both 1/2).
- **Same-window pairs are 14 of 20**, and 3 of those 14 flipped value outcomes (inwido, rusta,
  hexatronic) — a ~21% same-window flip rate is the model-variance floor at one run per (stem,
  arm). It cuts both ways: hexatronic's whole gain is variance-shaped, rusta's whole loss is not
  attributable to the flag with certainty. But the ✓-group net (−5 fields, −2 companies) is far
  outside that band, and its largest single term (rusta −4) is mechanism-consistent with the
  carrying sentence's wording on a lease-only borrower.

## Verdict (the work order's rule, applied)

**B 在 ✓ 组 < A:18/25 vs 23/25 字段,6 vs 10 家全对 → 建议默认关。** The hard group did move the
hint's way (+1 field, +1 all-✓ company, +3 page hits), and selection improved on both groups
(13/20 vs 10/20 routes, 13/26 vs 10/26 label pages) — but the moved selections did not convert into
values (fm_mattsson and alligo picked the right page and read it worse; vef and flerie swapped
windows for nothing), and the two largest value swings under identical windows (rusta 4/4→0/4,
hexatronic 2/4→4/4) show how much one-run variance this schema carries. If a future lane wants to
re-litigate the default, it needs paired same-window reruns (≥ 40 route pairs per arm) to separate
hint effect from variance, plus a tagger that (a) stops marking carrying pages as liquidity-risk
(medcap, flerie) and (b) covers lease-liability and "remaining term" note titles before the sentence
is safe for lease-only borrowers like rusta.
