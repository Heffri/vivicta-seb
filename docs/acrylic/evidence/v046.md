# v046 — debt_maturity bucket-label vocabulary: spelled-out and Swedish variants (zero-model)

Branch `ao/vivicta-seb-40/v046-bucket-synonyms`, off `origin/acrylic` (`33a1d3b` at dispatch, merged
forward to `01566a5` — v045's two-pass-v2 `extract.py` work and its 32 stored per-company
`debt_maturity` extraction snippets under `docs/acrylic/evidence/v045/` — before delivery; fast-forward,
no conflicts, since v045 never touched `debt_maturity.json`). Zero model calls, zero code changes:
`backend/schemas/debt_maturity.json` synonyms only, verified entirely offline against real report text.

## Method

Read every debt-maturity page cited by `v035.md`/`v037.md`/`v041.md` (seed 1/2/3's own locator/finding
tables) directly from `C:\...\uaw-lanes\vivicta-shared\seed{1,2,3}-kb\<stem>\pages.jsonl` (30 companies,
read-only) — the report's own printed bucket labels, not a synonym wishlist. For every candidate
addition: (1) checked it wasn't already covered (`_clean_label`-prefix or dash-normalised substring),
(2) grepped the *entire* 30-company corpus (all pages, not just debt pages) for the literal phrase to
catch collisions with unrelated notes (deferred tax, amortisation schedules, ESRS time-horizon
definitions — all recurring false-positive sources found this way), (3) for anything that still looked
risky, ran the real `_bucket_total_row`/`_bucket_header` gate by hand against the actual page text to
check whether a collision could reach value-fabrication (`_fill_bucket_columns`) or only the softer
`null_as_zero` confidence path (v044's mechanism). Three scripts (not committed, per territory —
`C:\...\uaw-lanes\v046\{dump_pages,safety_scan,hit_audit,full_corpus_diff}.py`): a page dumper, a
corpus-wide false-positive scanner, and two before/after checkers that run the real `_label_known` /
`_bucket_synonym_hits` from both `origin/acrylic`'s `extract.py` and the current one (same trick as
`scripts/label_regression.py`) against hand-catalogued real labels and then against every page of the
corpus. Their result tables are archived at `docs/acrylic/evidence/v046/hit_audit.md` and
`.../full_corpus_diff.txt`.

## What shipped: 26 new synonyms (36 → 62)

**`due_within_1_year`** (+5): `under 1 year`, `under one year` (work order's explicit "within / less
than / under" triad — `within`/`less than` already existed, `under` didn't; zero corpus hits either way,
so zero risk), `within 3 months` (Bergman & Beving p.120, Boozt p.108/121), `3-12 months` (Ework p.70,
Humana p.149, Hansa Biopharma p.64/65, Boozt p.108 — recurs in 4 independent reports), `inom ett år`
(work order's own headline Swedish example; Alligo p.141's real table, AcadeMedia p.97's own narrative
about its own debt).

**`due_1_to_5_years`** (+14): digit sub-buckets `1-3 years`, `2-3 years`, `3-4 years`, `4-5 years`
(Storytel p.114's own `1-3 years`/`3-5 years`* split; Coor p.159's `1–2/2–3/3–4/4–5 years` dash-form

report); prose `between 1 and 2 years`, `between 2 and 3 years`, `between 3 and 4 years`,
`between 4 and 5 years`, `between 2 and 5 years` (the work order's own headline example, literally
Ependion's p.155 and Gentoo Media's p.92 gap per v041/v044 — see Ependion note below; **also a clean,
unscrambled match found late in the audit**: Coor p.155's own lease-maturity table spells out
`Between one and two years` / `... two and three ...` / `... three and four ...` / `... four and five
years` / `After five years` in prose, a second independent company confirming the "between X and Y
years" prose form is real, current vocabulary, not just a hypothetical from the work order's title);
`one to five years` (Better Collective p.158/181's own lease-maturity rows); Swedish `mellan 1 och 3 år`,
`mellan 3 och 5 år` (XANO p.84's own header, scrambled — see below), `mellan ett och fem år` (the work
order's own headline Swedish example; XANO p.85 uses it verbatim for a different note, Alligo p.135 for
its own lease note, Knowit p.152 for several non-borrowings notes — all reviewed, see Safety section),
`inom fem år` (Alligo p.141/142's own 3-bucket table — kept as a judgment call, see below).

**`due_after_5_years`** (+7): spelled English `after five years`, `more than five years`,
`later than five years` (the digit forms were already all 4 present — `after`/`more than`/`later than`/

`senare än fem år`, `efter fem år` (spelled forms of the two that already existed in digit form — `efter

didn't have in *either* form yet; XANO p.87/109 — reviewed, see below).

`over five years` (spelled) was **not** added despite `over 5 years` (digit) already existing — see
"Tried, found risky" below.

\* `3-5 years` was deliberately **not** added — see below.

## Ependion and Gentoo Media: schema fixed, parser gap still blocks them (recorded, not routed around)

v041 diagnosed Ependion's gap precisely: its own header prints `Within 12 months / Between 1 and 2
years / Between 2 and 3 years` but the schema had no spelled-out synonym for either. v044 confirmed the
schema-vocabulary gap is real and explicitly out of *that* lane's territory. This lane closes the
vocabulary gap (`between 1 and 2 years`, `between 2 and 3 years` now both `due_1_to_5_years` synonyms)
— **but verified directly against the raw page text that this alone does not fix Ependion or Gentoo
Media**: both headers are scrambled by the same two-column pymupdf merge v041/v044/v036 already
diagnosed for XANO/Acast/Ework (`"Within 12 1 and 2 and / months 2 years 3 years Total"` — the words
"Within 12" and "months" are not contiguous in the extracted text, so no literal-substring synonym can
bridge them). Confirmed with the real `_bucket_synonym_hits` function against Ependion's and Gentoo
Media's actual page text: `within 12 months` still finds nothing there (and — see below — was excluded
from the synonym list anyway); `between 1 and 2 years` / `between 2 and 3 years` now match Ependion's
raw text as a **reconstructed** string only, not a **literal** one. A `parse.py`-level column-major fix
(HANDOFF's and `parse.py`'s own "next for a teammate" item) is what would actually unblock these two —
unchanged conclusion from three prior lanes, now re-confirmed with the vocabulary gap itself closed.

## Tried, found risky, not shipped

Corpus-wide grep (all pages, all 30 companies, not just debt pages) turned up four candidates with a
false-positive rate too high to ship, in the same spirit as v037's own "tried, found unsafe, reverted"
section:

1. **`within 12 months`** — 19 hits across the corpus, only 1 even tangentially on a debt page (Gentoo
   Media's own explanatory prose), the other 18 are deferred-tax, impairment (ECL) and
   liability-classification boilerplate (Bergman & Beving, Catella, Cloetta, NCAB, Humana, Hansa
   Biopharma, Flat Capital, VEF). Worse: its one real motivating case (Ependion) doesn't even benefit —
   scrambled, see above. Not shipped.
2. **`over five years`** (spelled) — 3 hits, all 3 unrelated (a CEO's "over five years, we have
   strengthened our margin..." and two intangible-asset amortisation-period mentions). 0/3 genuine.
   `over 5 år` (digit form, new preposition) was still added — that one's own evidence (XANO) is a
   genuine, on-topic debt note, just a different judgment call than the spelled English form.
3. **`3-5 years`** — 10 hits, 8 of them depreciation/amortisation useful-life tables (Better Collective,
   Acast, Ependion, Morrow Bank — fixed-asset and intangible notes, not debt) and a governance/voting
   table (Arjo); only 2/10 genuine (Storytel). `1-3 years` was kept (1/3 ambiguous, not clearly wrong);
   `3-5 years` was not.

`över 5 år`/`över fem år` (digit and spelled Swedish) were still added even though their own motivating
page (XANO p.87) turned out on closer reading to likely be a lease-liability sub-note rather than the
main interest-bearing-debt table (see Safety below) — kept because the false-positive count elsewhere in
the corpus was 0, not because the motivating case itself was clean; noted here so the "shipped" list
above isn't read as overclaiming a clean hit for that pair.
4. **`within one to five years`** — 0 corpus hits *including* its own motivating case (Boozt p.121 prints
   it as `"Maturity within\none to five\nyears"`, wrapped across 3 physical lines by the same
   header-wrapping issue v036 already diagnosed for XANO/Ework — a literal-substring synonym can't
   bridge a real newline either). The bare `one to five years` (no `within`/`maturity` prefix) was kept
   instead — same zero-risk profile, and it already covers this phrase as a substring wherever it
   *would* appear contiguously.

`inom 12 månader` (the Swedish analogue of #1) was not tested or added, for the same reason as #1 —
untested is not shipped.

## Safety: why the residual risk is bounded (verified against the real mechanism, not asserted)

A handful of new synonyms do fire on pages that aren't the target debt note (documented plainly, not
hidden): Knowit p.152 (interest-rate-swap and lease-liability notes, both using `Inom ett år`/`Mellan
ett och fem år`), XANO p.85/87/102/109 (an option-liability note, a lease sub-note, a parent-company-only
note, and its own ESRS time-horizon definition), NCAB p.117 (a **Parent Company** contractual-maturity
table — already caught by the schema's own `exclude_keywords: ["moderbolaget", "parent company"]` at the
locator level), Coor p.16/86 (a CEO's "after five years" reminiscence, and an ESRS climate time-horizon
definition using "1–3 years"), VEF p.20 (an interest-*coupon* cash-flow schedule v041 already ruled
out-of-scope for a different reason). Traced each against the real `_bucket_total_row`/`_bucket_header`
gate rather than assuming: **none of these can reach `_fill_bucket_columns`'s value-fabrication path**,
because that repair only fires on a row whose own label is either bare `Total`/`Totalt`/`Summa` or one
of `total_debt`'s own synonyms (`_bucket_total_row`) — every collision site above has its label glued to
something else by the same two-column-merge artifact (leaving no clean label at all) or is phrased
differently enough (`"Totala räntebärande skulder"`, word order reversed from the schema's `"räntebärande
skulder totalt"`; bare `"Borrowings"`, not `"total borrowings"`) to fail that gate. The one channel that
*is* reachable is v044's own `null_as_zero` row-search (softening a hard-failed check to "missing" when a
null bucket's own label happens to be findable somewhere on the page) — which only ever *raises*
confidence on fields that are otherwise already correct, never fabricates a value, and which v044's own
design already accepts this exact class of false-positive risk for (that mechanism, not this lane's
vocabulary, is what decides how permissive that search is).

**For the group**: ESRS/CSRD climate-risk "time horizon" definitions (Coor p.86, XANO p.109) are a new,
recurring false-positive source for debt-maturity-shaped phrasing (`"medium term as one to three years"`,
`"long term as ... over five years"`) — not chased further here since neither page scores on the
schema's own `keywords`/`toc_keywords` (no "borrowings"/"maturity structure" anywhere near them), so
`locate.py` wouldn't candidate them regardless, but worth knowing if a future lane ever widens the
keyword list.

`inom fem år` (Alligo) is the one genuine judgment call in this batch: taken literally it's ambiguous
("within five years" could mean cumulative-from-now or the report's own 1–5y partition), but Alligo's
own table verifies it as the latter by arithmetic (`68 + 2,272 + 0 = 2,340`, the report's own printed
future-payment total) — recorded plainly as a judgment call, same posture as v041/v044's own "recorded,
not silently assumed" findings.
