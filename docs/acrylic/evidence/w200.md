# w200 — saved discovery short-circuits web search

## Change

`POST /api/reports/discover` now checks local, same-year reports before it asks a
connected model to search the web. A match is deterministic only when the query
and saved company have equal `_name`/`slugify` keys, or when an exact ticker or
ISIN agrees. The cache contributes downloaded `reports/index.json` entries and
the KB contributes saved report metadata; directory metadata supplies ticker and
ISIN for legacy saved rows that do not carry them.

That path returns `source: "saved"` and `skipped_web_search: true`, emits
`saved report found, web search skipped` in the `directory` trace, and ends the
job without a `model_search` event. A prefix is deliberately uncertain and
continues to model search. `force_web: true` is the only override, exposed as
the **Search the web anyway?** action immediately under the search controls.

## Red → green

- **Red:** the new saved-first case in `pipeline.test_fetch` failed because the
  previous discover response had no `source` shortcut marker and continued into
  model discovery.
- **Green:** `python -m pipeline.test_fetch` passes. Its saved-first cases cover
  normalised-name, ticker, and ISIN matches with zero mocked model calls; the
  job trace; an explicit `force_web` model call; and an uncertain prefix that
  still calls the model. `test_collection.py` also proves API forwarding and
  the short job trace.
- **Frontend:** the new Playwright case in `ai-discovery.spec.ts` verifies the
  saved copy/action and that clicking it sends `force_web: true`.

## Real probe (22 September 2026)

The real Codex Terra allowance was used exactly twice: one browser click on
**Search the web anyway?**, and one trace capture of that forced request.

1. Sandvik FY2025 resolved from the saved KB record. Its recorded job stages
   are `directory → directory → done`; the second event says `1 saved
   match(es); saved report found, web search skipped`. There was no
   `model_search` event. The live UI is in
   [`w200/saved-shortcut.png`](w200/saved-shortcut.png), and its recorded job is
   [`w200/real-saved-job.json`](w200/real-saved-job.json).
2. Clicking **Search the web anyway?** for the same query reached the connected
   model and returned two candidates. Its trace is `directory → directory →
   model_search → model_search → model_search → done`; the live UI is in
   [`w200/forced-web-search.png`](w200/forced-web-search.png), and the forced
   trace is [`w200/real-force-job.json`](w200/real-force-job.json).
