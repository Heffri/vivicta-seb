## Green: narrow repairs

- `_row_year_column` now rejoins a visible two-year run only when contiguous calendar-year-only
  predecessor rows exactly double it. In the BICO shape it produces `(0, 4)` and only then looks
  past the two-line date stub for the adjacent `Group Parent Company` ordering.
- v110 now identifies actual compact section headings rather than a prose sentence that merely
  contains both scope words. Its title window admits the torn header's ninth line. Under the proven
  four-column orphan shape alone, a three-value detail row may receive one **trailing** nil; every
  column must still close to its printed section subtotal. No other short row is accepted.
- `_bucket_header` reads a copied header window through `_rejoin_torn_bucket_headers`. It requires
  adjacent `Within <n> Later than` fragments, a bare `year`, a standalone final `5 years`, and the
  CTT header context. It rebuilds `Within 1 year` and `Later than 5 years`, removes the non-column
  “Due for payment as follows:” lead, and leaves original rows/quotes untouched.

The frozen self-check replays the page shapes rather than reading mutable KB text:

- BICO: all-null answer → `total_debt=1286.8` (`218.3 + 1068.5`, `value_derived`) and
  `due_within_1_year=1068.5`.
- CTT: stored-total-shaped answer → `due_within_1_year=35.5`, the four 1–5-year columns and
  the later-than-five-year column align, and printed dashes become explicit zero buckets under the
  existing nil convention.
