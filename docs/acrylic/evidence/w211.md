# w211 — bounded second-pass default decision

## Decision

Keep `EXTRACT_SECOND_PASS` **off by default**. The required rule was: enable it only if the round-2
held-out value score did not fall and the count of non-empty wrong values did not rise. The enabled
run scored **29/40 values, 12/17 cited pages, 3 empty misses and 8 non-empty wrong values**, against
the frozen shipped-default result of **36/40, 14/17, 1 and 3**. The code default therefore remains
`0`; no extraction guard, schema, locator, label or KB data was changed.

The within-run comparison is stronger than the historical comparison alone. Before its follow-up
calls, this run's model answers scored 31/40 values and 12/17 pages, with 3 empty and 6 non-empty
wrong values. Applying the second pass to those exact answers added no correct value and two wrong
ones, ending at 29/40 with 8 non-empty wrong values.

## Protocol and call accounting

- Fixed sample and labels: the ten reports in `eval/heldout-smallcap-2025-r2.csv`. Existing isolated
  `pages.jsonl` snapshots were read without modification; repository `data/kb`, labels and PDFs were
  not written.
- Current lane baseline: `origin/acrylic` at `6d2d724`; provider `codex`, model
  `gpt-5.6-terra`, `FEWSHOT=0`, merge `off`, carrying debt basis, default strict schema, and
  `EXTRACT_SECOND_PASS=1`. `EXTRACT_SCAN_ALL`, `EXTRACT_TWO_PASS` and `PAGE_SELECT_HINTS` were unset.
- A wrapper around the real `call_llm` seam counted every actual model invocation and checkpointed
  after each call. The A group used **41 calls**: 16 first-pass calls plus 25 second-pass calls.
  The second-pass timings totalled **183.881 model seconds**, averaging **+2.5 calls and +18.4
  seconds per report**. Total A wall time was 392.373 seconds.
- The scored snapshots were then evaluated offline with `eval/run.py` and
  `scripts/eval_breakdown.py`; those scoring commands made zero model calls.

## B group — cut to preserve the experiment cap

The A group consumed 41 of the permitted 60 calls, leaving 19. A complete four-report off/on B
comparison needs at least eight first-pass calls and can add up to 24 bounded follow-up calls before
ordinary first-pass widening, so starting it could not guarantee the hard cap. Per the work order's
priority rule, B was cut in full; **no B-group model call was made**. NVIDIA debt maturity, AMD income
statement, Volvo debt maturity and Saab debt maturity therefore have no fabricated partial
off-to-on claim in this evidence.
