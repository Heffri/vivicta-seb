## Method

Followed v057's process with the v094 deltas. Read v051/v063/v072/v082 (the four hardening rounds) plus
v062/v066/v068/v069/v073/v083/v084/v085 (the fix tickets between them) in full first. Then, for **every one
of the 39 companies** (seed5-kb 11 + seed6-kb 10 + seed7-kb 8 + seed8-kb 10, stems in
`uaw-lanes\vivicta-shared\seed{5..8}-kb`), located the borrowings note / maturity table myself in
`pages.jsonl` (keyword scan, then full-page reads), cross-checked totals against balance-sheet lines and
financing reconciliations, and only wrote a value that is **printed on a page I read** — either verbatim,
or a sum of printed rows sanctioned by the schema's own finer-split/date rules (Proact, Tången, Net Insight,
Stillfront, Enea). Where a page's two-column layout scrambled the text (Stillfront p.109), the page was
rendered from the PDF and read as an image before trusting the row attribution. Every row's `notes` carries
the physical page number and a verbatim snippet (transliterated Swedish where the CSV's own style does).

Conventions applied (v057 precedents, v094 deltas):

- **Values as printed, in the report's native unit** (v057 Finding 3 — the backend reports as printed; a
  millions-converted label can never match). The v094 work order's "千位换百万" is honoured inside `notes`
  instead: every thousands-unit row carries its millions equivalent, e.g. "TSEK (= 89.5 MSEK)".
- **Zero-debt prose sentences** (BioGaia, Traction, Vicore): `total_debt = 0` + page only, no bucket rows —
  the v094 work order's explicit instruction (differs from v057's flat_capital 4-row treatment).
- **Reports with only a current/non-current split**: `total_debt` + `due_within_1_year` only; 1–5y/>5y rows
  not written (v094 instruction). Reports with a genuine carrying-basis maturity table get all printed
  buckets; dash-marked bucket columns stay `null` (v069's Ework convention — nil marker, not a printed 0);
  a printed digit `0` (Synsam, Duni) is labelled `0`.
- **Undiscounted/contractual bucket tables are never used for values** — those companies go to the
  "For Kristian" table (Instalco, VBG, ITAB buckets; whole-company cases below).
- **Leases follow the report's own aggregation**: note totals that include leases are labelled as such
  (Stillfront, Sdiptech, Meren, Byggmax, Öresund, Scandi, Bonava, FM Mattsson, SmartCraft, BioInvent,
  Net Insight); notes whose borrowings total excludes leases are labelled loans-only with the lease figure
  recorded in `notes` (Fasadgruppen, Synsam, Duni, VBG, Viaplay, Egetis, Tången, ITAB, Hexatronic).
