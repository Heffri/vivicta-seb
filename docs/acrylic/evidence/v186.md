## Predicate A — exact Parent Company-notes continuation

`_parent_notes_continuation` extends v111's entity-section guard only when an exact
Parent Company-notes running heading (English or Swedish forms) is among the first or
last two parsed page rows. This covers Balco's physical page header, which PyMuPDF
emits as the terminal row after the table. A generic occurrence of `parent` in prose
does not qualify. An explicit `Group` / `Koncernen` / `Consolidated` section heading
before the candidate closes the continuation and restores Group scope.

Green: Balco's valid Group `total_debt=540153` from p.90 is kept, while p.101's
`28157 / 538353 / 0` buckets become null with a warning naming the Parent Company
notes continuation. The committed counterexample begins with the same continuation
heading, re-opens `Group`, and keeps the later Group borrowing table readable.

Commit: `e391a3d` — `extract: extend Balco parent-note continuation guard (v111)`.

## Predicate B — generic rows in a local lease-only schedule

`_lease_only_maturity_context` classifies an otherwise unmarked table only when all
of the following are true:

1. the candidate is a generic Total or maturity-bucket row;
2. the bounded local context has a lease marker;
3. at least two actual maturity-bucket phrases are printed around the candidate; and
4. the same context has no borrowing, loan, debt, interest-bearing, credit-institution,
   or carrying-value signal.

The existing undiscounted-title verdict runs first, preserving v103's warning family.
An explicit `Group` section also rescues its own lease schedule (Rusta), as do normal
borrowings/bank-loan/carrying rows. Requiring a bucket ladder deliberately leaves
Sedana's lease-liability balance-sheet `Total 4,697` outside this predicate.

Green: G5's `1282 / 384 / 897 / 0` become null, each with a warning naming the
lease-only maturity schedule. The guard abstains; it does not manufacture the correct
zero from a separate p.94 sentence. A committed normal Group borrowing table that
includes both bank loans and lease liabilities remains readable. Existing Cloetta and
Rusta fixtures initially exposed over-broad versions of the predicate; the final
version retains both byte-for-byte in the full replay below.

Commit: `c16595b` — `extract: refuse G5 unmarked lease schedule (v103)`.
