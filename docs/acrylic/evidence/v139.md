## 2. The three changes (one commit each, locate_reach both sections before/after each)

0. **`locate: split the multi-year summary heading test into _summary_heading`** — pure predicate
   extraction out of `scored_pages`' summary penalty (v123's `years`/`QUARTER` logic, verbatim).
   locate_reach output **byte-identical on both sections** (diffed against the pre-refactor run).
   The companion below needs the same test: a five-year summary prints a balance sheet too.

1. **`locate: balance-sheet companion page joins the candidate window last`** —
   `balance_sheet_page(texts)` finds the group statement: a BS title (`balansräkning` / `balance
   sheet` / `statement of financial position` / `finansiell[aä]? ställning`) in the heading — the
   same first-150-chars window `scored_pages`' heading bonus reads — plus a totals anchor on the
   page, with the bottom-line equity-and-liabilities total preferred over `Total assets`/`Summa
   tillgångar` (fm_mattsson's liabilities continuation carries the former, not the latter, so the
   detector lands on the page holding the current/non-current debt block itself). Pages headed as
   the parent-company statement (`moderbolag`/`parent company`) and multi-year summaries are
   declined; of the qualifiers the consolidated-headed, bottom-line-anchored, lowest page wins.
   The page is **appended as the candidate list's last entry** — never ranked, nothing dropped, no
   reordering — so `scored_pages` is untouched (every company's rank columns stay byte-identical)
   and the PROMPT_BUDGET/window-prefix mechanics are exactly v123's: the appended page lands in the
   snippet-only tail two-pass page selection reads (fm_mattsson's pre-existing budget demotions
   shift it to index 8; the full-text prefix [123, 124, 121, 134] is identical to baseline).
   This is v123's "schema-level companion section" suggestion, implemented in the locator because
   the mechanism is generic (both existing sections are measured below; the income red line holds
   by construction and by measurement — appending cannot remove a candidate).

   **debt 100 → 103/105** (flerie 57, hansa 40, kabe 79 join as candidates and go unreachable→in;
   fm_mattsson's page 110 flips to `in` but its page 141 keeps the company unreachable).
   **income 102/102, 0 moves.**
