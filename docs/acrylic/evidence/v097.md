## Driver rule (why no call was duplicated, LESSONS 37)

Same rule as v082/v088/v090, built into a small driver (`uaw-lanes\vivicta-glm-38\driver.py`, not
part of the repo): before calling `/extract` for a `(stem, pass)` pair it checks whether the
evidence JSON already exists, and only calls the backend when it does not; every response is written
to its exact evidence path immediately on return. `urllib` timeout 600 s per call, above every
observed route (23–159 s this round). Fetches went through `POST /api/reports/fetch` with
`download_pdf: true`; five of the ten were already library entries (the fetch returned their `lib-`
report ids at zero download cost — the evidence files carry the plain stems), five downloaded fresh
off the MFN/Nasdaq feeds in 4–7 s. Backend run with `PYTHONUTF8=1`/`PYTHONIOENCODING=utf-8`.

(covered-set path indexing), which let the seed-9 overlap Viscaria through to one extract route

## Schema decision: two hypotheses built, replay-tested, both rejected with evidence

No schema commit — `backend/schemas/debt_maturity.json` is byte-identical to the dispatch baseline
(`git diff 05bc233` empty), as are `extract.py` / `parse.py` / `locate.py` as of this round's own
commits (the delivery merge then brought in v095/v096's extract.py changes, attested below). Every
replay below ran the stored answers through the real `extract()` on the KB's real page text with
`call_llm` stubbed (zero model calls), the v083–v088 method.

**H1 — RVRC, `"non-discounted liabilities"` (and `"ej diskonterade skulder"`) →
`ignore_header_synonyms` — provably inert.** RVRC's header says `non-discounted`, which the ignore
vocabulary misses, and that miss is why the fill reads the table. Adding the wording replayed
**same** — not because the words don't match, but because v076's own rule drops `_ignore` tags when
no carrying column exists anywhere in the table, and RVRC's page has none. The lever is structurally
inert on this shape; no wording can fix it. The refusal has to live in `_bucket_header`/
`_fill_bucket_columns` (extract layer, below). Same conclusion as v088-Karnell-#2 and
v090's "without maturity".

**H2 — Svedbergs, `"mellan 1 år och 2 år"`/`"mellan 2 år och 5 år"` → `due_1_to_5_years.synonyms`
and `"3 månader eller mindre"`/`"mellan 3 månader och 1 år"` → `due_within_1_year.synonyms` —
safe but undemonstrated, rejected.** The printed finer-split labels are absent from the vocabulary
(the baseline only has `mellan 1 och 2 år`-style forms, which do not substring-match the printed
`mellan 1 år och 2 år`). The additions did **not** fill the missing 1-5y bucket — the sibling-sum
read is extract-layer (no code path sums labelled sibling rows outside statement pages, v088
finding 2), so the only effect was a cosmetic `label_known` gain on the already-correct w1y sum,
its score still capped at 0.50 by the not-in-quote gate. Full-corpus replay with H2 applied:
**193 companies, 192 same, 1 changed** (that cosmetic evidence-list change only). Rejected per the
no-undemonstrated-changes rule: it changes the bucket scanner's inputs corpus-wide for zero value
movement — exactly the exposure v088 rejection 3 documented.

## For the group (what a future lane should pick up)

1. **The bucket repair needs a basis/scope guard in code.** Its "the page wins" step reads whatever
   table carries bucket-labelled columns when the model declines — including the liquidity note's
   undiscounted table (Lime) and an all-liabilities undiscounted maturity analysis (RVRC, where the
   identity then *endorses* 220 with trade payables inside). The v076 carrying-header tier only
   demotes when carrying wording exists to prefer; a table whose header says "non-discounted"
   must be refused in `_bucket_header`/`_fill_bucket_columns` — the `ignore_header_synonyms` lever
   is structurally inert when no carrying column exists (H1's replay).
2. **v096's residual vocabulary gap has two page-verified instances** (Svedbergs 435,842; Byggmästare
   1,911 — sums proven correct against the printed rows, both still null on the merged tree): the
   mechanism works where the vocabulary names the siblings (Rusta's `1–2 years`/`2–5 years`) and is
   blind to Swedish long forms (`Mellan 1 år och 2 år`). The route in is not plain synonym addition
   (H2's replay shows the fill still declines); it needs either a bucket-matcher label-tolerant form
   (`mellan X år och Y år` as a pattern) or v096's sibling detection to read the `_BUCKET_BOUNDARY`
   year ranges off the row labels themselves.
3. **Fagerhult's 1.2 confidences**: after the identity-kept path, `value_derived` and
   `value_in_quote` coexist in evidence, breaching WEIGHTS' "never both" intent and pushing scores
   above the documented 1.0 ceiling — scoring-layer, for whoever owns the merge-era interactions.
4. **Rejlers' printed dash rows** (`1-2 years - -` …) produced 0@0.25 with "quote not found" instead
   of a verified `printed_nil` — the dash-to-0 gate never engages when the model itself answers a
   non-null 0 with a multi-row dash quote. Generalises v090's Linc item: printed-nil today only
   fires inside the bucket repair.
5. **Byggmästare's instability is timeout-shaped** (pass2's main call died at 120 s; the single-page
   retry answered from a different page than pass1) — the LESSONS 37 family; the driver held (no
   resend), the variance is model/route-side.
