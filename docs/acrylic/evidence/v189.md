# v189 — ESEF/iXBRL total-debt coverage probe

## Scope and method

This is a **read-only feasibility probe**, not an implementation. It used the 105 saved
`debt_maturity` records, sorted their stems lexicographically, and selected the first 15:
AcadeMedia, Acast, Alligo, Ambea, Apotea, Arctic Paper, Arjo, Attendo, Avarda Bank,
Bergman & Beving, Better Collective, BHG Group, BICO Group, BioGaia, and BioInvent
International. Every selected extraction is FY2025 and records `maturity_basis: carrying`.

For each selection the lane-local, one-off probe read the company ISIN from
`data/companies.json`, read `total_debt` plus its unit/basis from the saved extraction, and then:

1. called GLEIF's `lei-records?filter[isin]=<ISIN>` endpoint;
2. called `filings.xbrl.org/api/filings?filter[entity.identifier]=<LEI>`;
3. chose the returned filing with the latest `period_end`, then fetched its `json_url`;
4. selected only exact `ifrs-full:Borrowings`, `CurrentBorrowings`,
   `NoncurrentBorrowings`, and `LeaseLiabilities` facts that were monetary, instantaneous at
   the reported close date (or its next-day instant representation), and not marked parent or
   separate-company. An explicit consolidated context would win; otherwise the default,
   unsegmented context was retained and labelled as such.

Only `api.gleif.org` and `filings.xbrl.org` were contacted. Requests were serialized with a
1.1-second pause. A dash below means that the **exact requested tag** yielded no selected fact;
the probe did not silently substitute a different taxonomy concept. Local totals were normalized
only within their printed currency (SEK, EUR, or PLN) and could match only the same fiscal year
within ±1%.

- **exact standard-tag coverage:** 0/13 returned filing documents supplied any one of the four
  requested tags under the stated fact policy. Thus **comparable is 0/15 and match is 0/0**;
  `0/0` is an unavailable denominator, not a success rate.

The documents are reachable, but the target tag set is not a portable total-debt interface. For
example, AcadeMedia's latest document exposes `ifrs-full:LongtermBorrowings` (1,666,000,000 SEK)
and `CurrentPortionOfLongtermBorrowings` (446,000,000 SEK), plus
`NoncurrentLeaseLiabilities` (9,408,000,000 SEK) and `CurrentLeaseLiabilities`
(1,574,000,000 SEK), rather than any of the four requested tags. Those facts were deliberately
not repurposed as a total in this probe: doing so would make a lease-inclusion and taxonomy-mapping
policy without an approved definition.

## Decision — do not implement now

**Do not add ESEF/iXBRL as a `total_debt` source now.** The GLEIF hop is usable, and the repository
coverage is superficially promising (13/15), but there is no FY2025 document in this sample and
none of the requested standard tags supplies a candidate. An implementation would first need a
maintained tag-family map, an explicit carrying-versus-lease policy, and current-period coverage;
otherwise it would create unreviewable false mismatches. That is more than adding a sixth fetch
source or a single evidence flag.

If a later probe establishes those prerequisites, the proposed (not implemented) evidence slot is:

```text
esef_match = {
  status: "match",
  lei: "...", isin: "...",
  filing_period_end: "YYYY-MM-DD", xbrl_json_url: "...",
  concept: "ifrs-full:<mapped concept>", fact_ids: ["..."],
  context: "explicit consolidated" | "unsegmented/default",
  candidate: "direct" | "current_plus_noncurrent" | "plus_leases",
  raw_value: number, unit: "ISO currency", normalized_value: number,
  local_value: number, local_unit: string, maturity_basis: "carrying",
  tolerance: 0.01, relative_difference: number
}
```

It may be written only when the ISIN→LEI mapping is unique, filing period equals the saved fiscal
year, currency/scale are explicit, the fact context is not parent/separate, and the mapped values
close within ±1%. `esef_unavailable` and `esef_mismatch` must remain explicit reasons/warnings;
they must not improve field confidence, rescale a value, or claim support for maturity buckets.

## Red/green and verification

- **Red:** a first fact selector compared the XBRL instant string literally to `period_end`.
  AcadeMedia's live facts use the next-day `T00:00:00` form, falsifying that selector.
- **Green:** the corrected selector compares the date component at close or close+1 day, then the
  serialized low-rate probe completed all 15 records. Its assertions were 15 selected, 14 LEIs,
  13 filings, 0 FY2025 latest filings, 0 requested-tag hits, 0 comparable records, and 0 matches.
  This corrects the probe only; it changes no product behavior.
- No repository code or `data/` file was changed. `backend/pipeline/fetch.py` was read only; its
  existing source order has no ESEF source. A read-only UAW inventory found no wired ESEF/iXBRL
  helper suitable for adaptation.
- The lane-local probe and its JSON output remain outside the repository. The repository change is
  this evidence document only.

- Frontend verification on the unchanged product: `npm ci` completed with 365 packages and no
  audit vulnerabilities; `npm run build` passed (2,122 modules transformed); `npm run lint` passed
  with 13 existing warnings and no errors.
