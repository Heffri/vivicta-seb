## Reproduction and root cause

### AMD page selection

AMD FY2025's actual consolidated statement is PDF page 72 (printed page 60).  Its text layer already
contained the closing row `Net income ... $ 4,335 $ 1,641 $ 854`; `_page_rows` therefore was not the
failure point.  Before the change the page ranked 11th and missed the ten-page candidate budget, so the
extraction prompt did not include that page or its Net income row and no guard could accept a value from it.

The cause was schema-only: the normal US 10-K heading `ITEM 8. FINANCIAL STATEMENTS AND SUPPLEMENTARY
DATA` matched the income schema's `supplementary` exclusion.  That incorrectly applied the exclude
penalty to a page whose report title is `Consolidated Statements of Operations`.  `net_profit` already had
`net income` as a synonym; no synonym addition was needed.  Removing only that generic exclusion raises
AMD page 72 to rank 1 without changing `locate.py`.

`pipeline.test_locate` has a compact real-title AMD fixture plus ten decoys.  It was red before the schema
change (the statement at fixture page 11 was absent from candidates) and is green now.

### Intel text layer

Intel FY2025 page 66 took `_best_words` and yielded an overlaid positional layer such as `Net Net income
income ... 26 26`.  Locator phrases and field synonyms could not match it, so the real statement was not
selected.  `_dedupe_doubled_tokens` applies only after a page-wide signature of at least eight adjacent
repeated-token pairs and at least a quarter of tokens duplicated.  It collapses two or more overlaid copies
on every `page_text` return path while leaving normal prose repetitions untouched.  The Intel fixture in
`pipeline.test_parse` covers both cases.

### Ask table continuity

The 800-character page windows split AMD's long statement: the selected keyword hit stopped before the
later Net income row, so the original Ask response correctly said the supplied excerpt did not contain
`Profit for the year`.  BM25 ranking is unchanged.  For a selected page-window that contains at least three
numeric `_page_rows`, Ask now expands to its contiguous table neighbours, bounded at 4,000 characters; the
usual 1,600-character global cap still applies to prose and fact hits.  The AMD fixture proves the returned
hit includes both `Other income (expense), net` and `Net income $ 4,335 $ 1,641 $ 854`.
