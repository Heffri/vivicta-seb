## Findings (premise-level and corrections to earlier evidence)

1. **Ambea — v088's "year-column corrected" values are the 2024 comparatives; the stored `data/kb`
   answer (10,757 @1.0) is the wrong year.** Note G18's header prints `31 Dec 2025 | 31 Dec 2024`
   — 2025 **first** — and 10,335+2,308=12,643 closes in the first column, 8,878+1,879=10,757 in the
   second. Anchored independently: p.126's prose "commercial paper with a value outstanding of SEK
   **1,232 million (1,039)**" puts the current year's 1,232 in the same first column (it is a
   component of 2,308), and p.119 was rendered and image-verified. v088's `_row_year_column`
   correction (12643→10757, 2308→1879) fired on a page whose header already had the current year
   leftmost — the same false-flag family v090 documented for Tången. Labels 12,643 / 2,308 score ✗
   against the stored extraction **by design**; the stored answer needs re-extraction, not the label.
2. **Flerie — v090's premise ("the real debt table hidden behind the two-column scramble,
   `Konvertibellån 104,8`") is overturned: 104.8 is an asset.** p.57's `Konvertibellån 21 104,8
   57,1` sits inside *Omsättningstillgångar* (current assets) between Skattefordringar and
   Lånefordringar portföljbolag, and Note 28 classifies it under *Finansiella tillgångar* (fair value
   through P&L) — convertible loans **to** portfolio companies. Flerie's interest-bearing
   liabilities are leases only: 2.1 (Note 28 bokfört; BS 1.6+0.5; Note 17 prose). The stored 0.4 was
   a lease roll-forward fragment, as v090 suspected — but of a 2.1 company, not a 104.8 one.
3. **Dynavox — the carrying line v088 said was "never located" exists on p.133.** The
   financial-liabilities reconciliation prints `Interest-bearing loans 24 896.2 896.2 691.5 691.5`
   (2025 nominal = carrying), tying Note 24's roll-forward closing and the BS (828.8+67.5). The
   893.8 v088 stored is the financing-movement figure (691.5+202.4, parent-statement family). So the
   work order's "找不到就列争议表" branch did not trigger: labelled 896.2.
4. **NOTE — the number the model dropped as "computed, not read" is printed in the report.** Not 19's
   two Summa rows sum to 824,281 (TSEK), and p.109's liquidity-risk prose prints "räntebärande
   skulder **824,2 (630,0) MSEK**" — a printed total in prose, the Enea shape. The extract-layer
   guard demanded a digit inside the quote while the printed source carries it in millions with a
   comma decimal. Also disclosed: the BS's own interest-bearing lines (125,201 + 571,428 = 696,629)

   note the report itself titles "Räntebärande skulder", corroborated by the p.109 prose.
