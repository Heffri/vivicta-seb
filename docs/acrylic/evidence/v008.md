## 改了什么

1. **`scripts/random_check.py`**:`--exclude-sector "Real Estate"`(可重复,按 `sector` 字段子串剔除;`--market` 子串匹配照旧)。抽样池 = Mid Cap 剔除 Real Estate = **107 家**,与 HANDOFF 的 universe 一致。`python scripts/random_check.py --help` 显示参数在;未真跑抽取(要 :8000 + Ollama)。
2. **`scripts/locate_check.py`(新)**:对 `data/kb/*/pages.jsonl`(102 家逐页文本,`{"page": n, "text": ...}` 每行一条)按 `--section debt_maturity`(默认)跑 `locate.candidate_pages()`,打印每家前 5 候选页 + 标题窗口(前 150 字,压缩小写)前 80 字 + 粗判定标志。`--only <子串>` 过滤,`--top 5`。
   - 粗判定 = 页内(与评分同一份 strip_boilerplate 文本)同时出现 maturity 词(`matur|förfall|due`,排除 "due to")、≥1 个 schema 字段 synonym、数字密度 ≥ 0.05。**纯启发式,给人看的辅助标记,不是分数**;词表是债务注释形状,对 income_statement 无意义(下面 income 的表只看排名,不看标志)。
3. **`backend/pipeline/locate.py`**:
   - `toc_targets(texts, schema)`(新,公开函数):在前 8 页里找含 `contents`/`innehåll` 的目录页,从**原始**文本解析条目(先于 strip_boilerplate 剔除——已有 `TOC_LINE` 把目录行当评分噪声的逻辑原样保留,顺序是"先提取、再剔除")。三种条目形状:引导线式 `AAK in brief________________7`、同行空格式 `Business area: Vacuum Technique  25`、标题行+独立数字行式(Atlas Copco)。
   - `_folio_offset(texts)`(新):印刷页码 → PDF 页序的偏移,每报告一个,由**全部页面**的页边缘(前 3 行/后 3 行:整行只有 1–3 位数字,或行尾空格+1–3 位数字,如页脚 "Atlas Copco Group 2025   2")投票产生;得票 < max(8, 8% 页数) 视为对不齐 → 返回 None。**对不齐就不加权,不猜**:目录目标页还必须在自己的页边缘真的印着那个印刷页码,否则丢弃。
   - `candidate_pages()`:目录指向的页在加法项 +5。**量级理由**:与现有 `+5 heading` 同档——目录条目是报告用自己的话给页面命名,和"关键词出现在页首标题"同为一比特强证据;更强(比如 +15)会让一条目录行压过页面自身的证据栈(heading+synonyms+数字密度),而 Swedbank 的目录恰恰指向一张分节扉页,证明这种压制是危险的。目录条目标题同时过 schema `keywords + toc_keywords`,并先过 `exclude_keywords` 排除。
4. **`backend/schemas/debt_maturity.json`**:新增可选 `toc_keywords`(borrowings / upplåning / räntebärande skulder / interest-bearing liabilities(+无连字符拼写)/ maturity / maturities / förfall / loans payable / liquidity risk / likviditetsrisk)。通用词,进 schema 不进代码;页面 `keywords` 未动。

## 印刷页码对齐规则(为什么能对齐、什么时候放弃)

- 每页取前/后 3 行,提取独立短数字候选;对每页每个候选投一票 `pdf页 − 印刷页`。真实 folio 让同一个偏移得到全报告级别的多数(aak 118/190 票 offset 0;abb 137/142 票 offset +2;atlas_copco 页脚嵌数字也投出稳定 +2);页眉页脚外的数字噪声票数摊薄。
- 赢家需 ≥ max(8, 8% 页数) 票,否则 None:**102 家里 77 家对齐成功,25 家放弃**(ericsson、hexagon、saab、saab_2025_sv、seb、sv_handelsbanken、telia、trelleborg 等——页面边缘根本不印页码,或噪声淹没投票)。
- 即便偏移成立,每个目录目标还要复核:目标 PDF 页的页边缘必须真印着该印刷页码,否则该条目丢弃(防个别页无 folio / 装帧偏移)。

## v008b —— 两张表问题:exclude_keywords 实验 + neighbour scoring 实验(均净负,已回退)

主管指令:两张表问题(aak p.145 liquidity-risk 压 p.169 borrowings)先试 schema 手段,不够再试 neighbour scoring,各做 before/after。基线 = v008 终态(`after_fulldoc.txt` / `is_after_fulldoc.txt`)。**两个实验都净负,代码已回退,当前 locator 保持 v008 状态;数字如下。**

### 实验一:schema exclude_keywords(debt_maturity.json)

加入通用词:`liquidity risk / likviditetsrisk / undiscounted / odiskonterade / contractual cash flow / kontraktuella kassaflöden`(同时从 toc_keywords 语义上被 exclude 压制;评分端 = head 含词 → x0.1 惩罚,目录端 = 该标题条目不再加分;`extract.py` 提示词的 "Ignore … about" 也会同步带上这些词——这是 exclude_keywords 的既有耦合)。

结果(`after_v008b.txt` vs `after_fulldoc.txt`,逐页核验见 `v008b_top1_changes.txt`):**top-1 变化 21 家 = 改善 2 / 伤 16 / 中性 3**。

- **改善 2**:aak(p.145 → p.169 note 20 borrowings,主管点名的案例)、essity(e5 → e4 financial liabilities carrying-amount 页,mat/bor/bucket 三项全真)。
- **伤(典型)**:aq(p.73 note 3.6 的 terms-and-maturity 表 → p.66 资产负债表)、electrolux_professional(note 18 **maturity profile** 页 → liquid funds 页)、seb(**group** g37e contractual maturity 表 → **parent** p36 页——group/parent 排除词管不住 "p36" 这种编号)、swedbank(2.2 summary of maturities → parent p33 列表)、4c/alvotech/asmodee/avanza/volvo_car/yubico(到期页跌落后顶上来的是风险因子散文、关联方交易、现金流量表、租赁页)。
- income_statement:逐字节不变(不同 schema 文件,机制上不可能受影响,已跑证)。

**为什么净负**:对多数发行人,contractual 到期表本来就印在标题带 "liquidity risk" 的页里(seb/swedbank/arion/sca/essity/aq…的 top-1 全是);exclude 无法区分同一注释标题下的"散文段"与"到期表段"。哪张表该赢是 HANDOFF 开放问题 #1(Kristian:carrying 还是 contractual)——schema 单侧拍不了板。顺带的发现:被压页跌落后顶上来的常是无防备的垃圾页(散文/parent/租赁),排除只有惩罚、没有"存在更优页"的前提检查。

### 实验二:neighbour scoring(locate.py "Next" #2)

实现:页 p 得分后,若 p±1 也有分,加平坦 bonus(乘数之后)。NEIGHBOUR=2:debt top-1 变化 **8 家且几乎全为退化**(engcon 的 note 28 borrowings note 被利率风险页挤掉、sagax 的 future liquidity flows 到期表被 note 30 抵押品页挤掉、mycronic/oem/traton/truecaller/billerud/new_wave 同型);income top-1 变化 0、101/101 source page 保持、top-3 变化 debt 26 / income 6。NEIGHBOUR=1:debt top-1 仍变 6 家,同型退化(量级无关,机制缺陷):**孤立但正确的到期表页,输给"成串得分"的相邻注**——bonus 奖励的是注的密度,不是页的正确。回退。

### 给小组的建议(两张表)

1. 这个分叉必须由 owner 拍板(HANDOFF 开放问题 #1):**borrowings note(逐笔借款+maturity date)vs liquidity-risk note(contractual undiscounted 到期表)**。拍板前任何关键词加权都会在 17 家"到期表在 liquidity 页"的发行人身上翻车。
