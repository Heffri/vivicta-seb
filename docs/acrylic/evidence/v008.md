Lane `ao/vivicta-glm-4/v008-locator-toc`,基线 `origin/acrylic`。一切验证离线、确定性:没有 Ollama / 独显,没起任何服务,没下 PDF。

## 改了什么

1. **`scripts/random_check.py`**:`--exclude-sector "Real Estate"`(可重复,按 `sector` 字段子串剔除;`--market` 子串匹配照旧)。抽样池 = Mid Cap 剔除 Real Estate = **107 家**,与 HANDOFF 的 universe 一致。`python scripts/random_check.py --help` 显示参数在;未真跑抽取(要 :8000 + Ollama)。
2. **`scripts/locate_check.py`(新)**:对 `data/kb/*/pages.jsonl`(102 家逐页文本,`{"page": n, "text": ...}` 每行一条)按 `--section debt_maturity`(默认)跑 `locate.candidate_pages()`,打印每家前 5 候选页 + 标题窗口(前 150 字,压缩小写)前 80 字 + 粗判定标志。`--only <子串>` 过滤,`--top 5`。
   - 粗判定 = 页内(与评分同一份 strip_boilerplate 文本)同时出现 maturity 词(`matur|förfall|due`,排除 "due to")、≥1 个 schema 字段 synonym、数字密度 ≥ 0.05。**纯启发式,给人看的辅助标记,不是分数**;词表是债务注释形状,对 income_statement 无意义(下面 income 的表只看排名,不看标志)。
3. **`backend/pipeline/locate.py`**:
   - `toc_targets(texts, schema)`(新,公开函数):在前 8 页里找含 `contents`/`innehåll` 的目录页,从**原始**文本解析条目(先于 strip_boilerplate 剔除——已有 `TOC_LINE` 把目录行当评分噪声的逻辑原样保留,顺序是"先提取、再剔除")。三种条目形状:引导线式 `AAK in brief________________7`、同行空格式 `Business area: Vacuum Technique  25`、标题行+独立数字行式(Atlas Copco)。
   - `_folio_offset(texts)`(新):印刷页码 → PDF 页序的偏移,每报告一个,由**全部页面**的页边缘(前 3 行/后 3 行:整行只有 1–3 位数字,或行尾空格+1–3 位数字,如页脚 "Atlas Copco Group 2025   2")投票产生;得票 < max(8, 8% 页数) 视为对不齐 → 返回 None。**对不齐就不加权,不猜**:目录目标页还必须在自己的页边缘真的印着那个印刷页码,否则丢弃。
   - `candidate_pages()`:目录指向的页在加法项 +5。**量级理由**:与现有 `+5 heading` 同档——目录条目是报告用自己的话给页面命名,和"关键词出现在页首标题"同为一比特强证据;更强(比如 +15)会让一条目录行压过页面自身的证据栈(heading+synonyms+数字密度),而 Swedbank 的目录恰恰指向一张分节扉页,证明这种压制是危险的。目录条目标题同时过 schema `keywords + toc_keywords`,并先过 `exclude_keywords` 排除。
4. **`backend/schemas/debt_maturity.json`**:新增可选 `toc_keywords`(borrowings / upplåning / räntebärande skulder / interest-bearing liabilities(+无连字符拼写)/ maturity / maturities / förfall / loans payable)。通用词,进 schema 不进代码;页面 `keywords` 未动。

## 印刷页码对齐规则(为什么能对齐、什么时候放弃)

- 每页取前/后 3 行,提取独立短数字候选;对每页每个候选投一票 `pdf页 − 印刷页`。真实 folio 让同一个偏移得到全报告级别的多数(aak 118/190 票 offset 0;abb 137/142 票 offset +2;atlas_copco 页脚嵌数字也投出稳定 +2);页眉页脚外的数字噪声票数摊薄。
- 赢家需 ≥ max(8, 8% 页数) 票,否则 None:**102 家里 77 家对齐成功,25 家放弃**(ericsson、hexagon、saab、saab_2025_sv、seb、sv_handelsbanken、telia、trelleborg 等——页面边缘根本不印页码,或噪声淹没投票)。
- 即便偏移成立,每个目录目标还要复核:目标 PDF 页的页边缘必须真印着该印刷页码,否则该条目丢弃(防个别页无 folio / 装帧偏移)。

## 给小组的建议

1. debt_maturity 定位错的真实形态是 **liquidity-risk / financial-risk note 压过 borrowings note**(aak:p.145 压 p.169),不是"找不到带关键词的页"。比起继续加目录魔法,更值钱的是 HANDOFF 里已有的两条:candidate_pages "Next" 第 1 条(**neighbour scoring**:注释成对出现),以及 HANDOFF 正文说的**两张表区分**(contractual undiscounted vs carrying amount)——后者 extract/schema 就能表达。
