# v190 — held-out Small Cap 2025 round 2

## Claim, boundary, and source review

Round 2 is a deliberately small blind measurement, **not** a market-accuracy claim. It uses a new
FY2025 Small Cap sample drawn with `seed=2`, after excluding all 17 companies that round 1 either
extracted or skipped. Round 1 (`v178`) was later examined to attribute failures and develop the
v185/v186 guards, so it is now a historical guard/tuning measurement rather than the current
held-out benchmark. No result in this round changed a label, prompt, schema, pipeline behavior, or
shipping decision.

The UAW `demo` tree was searched for held-out/random/evaluation implementation before work began.
It had no applicable implementation for this isolated report-selection-and-scoring protocol, so no
UAW code was copied. This documentation/label lane changes no application code, `data/kb`, or
`eval/labels.csv`.

## Isolation, sampling, and blindness

- The backend used an empty isolated `ARP_DATA_DIR`; only `data/companies.json` was copied into it.
  Its report index, reports, KB, and uploads began empty. No repository KB content was read or
  written.
- Configuration was `LLM_PROVIDER=codex`, `LLM_MODEL=gpt-5.6-terra`, `FEWSHOT=0`, and carrying
  debt basis. `/api/config` confirmed the real primary setting `EXTRACT_MERGE_RUNS=off`; all other
  optional extraction switches were unset. The comparison restarted the same isolated backend with
  `EXTRACT_MERGE_RUNS=majority` only.
- The seed-2 traversal fetched PDFs only before labelling. Fixed sample: Vivesto, NAXS, Active
  Biotech, Ascelia Pharma, Catena Media, Bong, Duroc, Stockwik, Xspray Pharma, and PION Group.
  The round-1 exclusion list contains 17 companies; four were encountered and bypassed during this
  seed-2 traversal.
- Nine non-selected fetch outcomes were recorded: eight scan/OCR HTTP 422 cases (Acrinova,
  Railcare Group, Actic Group, Lammhults Design Group, C-RAD, Q-Linea, mySafety Group, and Arla
  Plast) and one non-JSON HTTP 500 (Björn Borg). The eight OCR cases are separately counted; none
  is an extraction result.
- Before labelling, the red observation was that
  `eval/heldout-smallcap-2025-r2.csv` did not exist. The green structural check parsed 40 rows for
  10 reports and exactly four `debt_maturity` keys per report. The blind-label commit is
  `2051c4f` (`eval: add blind Small Cap round 2 labels`), made before any extraction output, stored
  result, or model-response body was opened. No label changed after that commit.

## Same-label comparison — non-default `majority`

The comparison used the same PDFs, same isolated pages, and unchanged frozen labels. Its own
snapshot scored **36/40 (90.0%)** values and **14/17 (82.4%)** cited pages: the same **1 empty**,
**3 non-empty wrong**, and **2 page-only** rows as the primary result. Eight reports agreed with
the stored default result after one comparison run; Active Biotech and Stockwik needed a second
run. No scored value or cited page changed.

The primary run's recorded extraction attempts sum to **18** and the majority comparison's to
**22**, for **40 extraction calls total**, exactly the permitted cap. The following commands score
only stored snapshots and make no API, network, PDF, or model call:

```powershell
python eval/run.py --labels eval/heldout-smallcap-2025-r2.csv --stored-kb <default-off-snapshot> --no-fail
python scripts/eval_breakdown.py --labels eval/heldout-smallcap-2025-r2.csv --stored-kb <default-off-snapshot> --section debt_maturity
python eval/run.py --labels eval/heldout-smallcap-2025-r2.csv --stored-kb <majority-snapshot> --no-fail
python scripts/eval_breakdown.py --labels eval/heldout-smallcap-2025-r2.csv --stored-kb <majority-snapshot> --section debt_maturity
```
