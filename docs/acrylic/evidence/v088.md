## Schema decision: four hypotheses investigated, all rejected with evidence

No schema commit — `backend/schemas/debt_maturity.json` is byte-identical to
the dispatch baseline. Every rejection below was replayed through
`extract()` with `call_llm` stubbed to the stored pass answer and the KB's real
page text (the v083/v084/v085 method, zero model calls). One caveat
disclosed up front: stored fields are post-repair, so a replay can trigger
paths the live run never took — and did, once (see the Rusta note in 3).

**1. Karnell, `">3 years"` → `due_after_5_years.header_synonyms` — harmful.**
Karnell's `<1 year` header is already matched (`_BUCKET_BOUNDARY`'s
`<\s*1\s*years?`), so the header reads 3 keys (`within1y, 1-5y, total`) against
the row's 4 printed amounts and the length valve declines everything. Claiming
`>3 years` opens the path — and the fill lands on the **all-liabilities Total
row** (`Total 72.2 354.4 107.0 533.5`, which sums earn-outs, put/call options
and accounts payable), giving `total_debt=533.5` with `maturity_sums_to_total`
**passing** — a wrong-scope value the check itself endorses. Bare-Total rows
are tried before debt-row candidates, and no schema key can express "this
Total is the wrong scope". Candidate-order/scope is `_bucket_total_row`/
`_fill_bucket_columns` territory.

**2. Karnell, `">3 years"` → `ignore_header_synonyms` — a no-op, with the
reason on record.** Replayed: all four fields stay null, no warnings. v076's
own rule (extract.py's `_bucket_header`: "without a carrying hit anywhere, the
_ignore tags are dropped") strips the ignore hit because Karnell's header has
no carrying wording — the length valve then re-closes at 3-vs-4.

**3. Rusta, `"0-6 months"/"7-12 months"` → `due_within_1_year.synonyms` — not
inert, actively harmful.** The schema's own read of these rows can never
produce the sums (no code path sums finer-split sibling rows outside statement
pages — `_statement_row` deliberately declines two rows matching one field),
so the hypothesis was "harmless vocabulary". Replayed: the additions leak into
`_bucket_synonym_hits` (it reads `synonyms + header_synonyms`), turning data
rows like `0–6 months 523` into bucket-naming lines inside the 25-row header
window and **changing `_bucket_header`'s read** — the baseline replay's one
fill (607 from the Parent Company commitment table, itself a replay artifact
the live run's computed-not-read guard correctly suppressed — the stored
answers are post-repair, exactly the v083 caveat) disappears. Rejected, and
recorded as a concrete trap: **for the bucket fields, `synonyms` are bucket-
scanner input, not inert row vocabulary** — every future word addition must go
through the full-corpus replay gate, which is what it is for.

**4. Inwido, locator keywords — unreachable within the safe direction.**
locate.py scores p.143 (Note 3, the undiscounted maturity-structure page)
11.09 vs ~1.6 for p.165/166 (Note 21, the carrying row) — no keyword addition
closes that without v017's documented net-negative re-ranking risk. Root cause
of the missing TOC boost that should have surfaced Note 21: Inwido's folios
print the number at line *start* (`165 Annual Report 2025 | ...`), which
`_folios`' end-of-line patterns never match, so `_folio_offset` returns None
and `toc_targets` is empty report-wide — code-layer, named for whoever picks
it up.

## For the group (what a future lane should pick up)

1. `_bucket_total_row`/`_fill_bucket_columns` candidate order and scope: a
   table-wide bare-Total row (Karnell's 533.5) outranks the interest-bearing
   row; `known_total`-style narrowing cannot help when the model answer is
   null. The v084 year-narrowing pattern suggests the next general rule:
   prefer the row whose label is a `row_synonyms` debt word over a bare Total
   when both survive, or read the table's title wording as scope evidence.
2. Finer-split sibling-row sums (Rusta): a row-per-bucket table with
   `0–6 months / 7–12 months` and `1–2 years / 2–5 years` needs the bucket
   repairs to sum labelled siblings; the identity (1,039 + 3,153 + 2,431 =
   6,623 ≈ 6,624) proves the reading.
3. `_folios`: folios printed at line start (`165 Annual Report 2025 | ...`)
   disable the TOC boost for the whole report (Inwido; likely other layouts).
4. Viscaria's override: the bucket repair's "the page wins" step should not
   reach an undiscounted per-instrument table through a lease-only row
   candidacy when the model's own answer already matches the note's
   current/non-current split.
