# v178 — held-out Small Cap 2025 first extraction

## Claim and guardrails

This is a small, blind, held-out measurement — **not** a market-accuracy claim. The sample is
ten FY2025 Small Cap reports drawn with `seed=1`; these reports had not been used in the existing
seed sets or `eval/labels.csv`. The held-out CSV remains separate and every row says
`held-out: not for tuning`; it must never be copied into `labels.csv`, prompts, few-shot examples,
or a tuning/release decision.

All writes occurred under an isolated `<lane-temp>/heldout-data` directory. Its `kb`, `reports`
and `uploads` directories began empty. Bootstrap required only read-only copies of
`data/companies.json` and `data/reports/index.json`; no repository `data/kb` data was read or
written, and no extraction result was published into it.

## Configuration, sampling, and blind-label chronology

- Backend: `ARP_DATA_DIR=<lane-temp>/heldout-data`, `LLM_PROVIDER=codex`,
  `LLM_MODEL=gpt-5.6-terra`, and `FEWSHOT=0`. `EXTRACT_TWO_PASS`, `PAGE_SELECT_HINTS`, and other
  optional environment switches were unset.
- `/api/config` confirmed the real shipped merge default is `off`; it was not changed. The primary
  run therefore used `EXTRACT_MERGE_RUNS=off`. The later `majority` run was an explicitly
  non-default comparison on the same PDFs and frozen labels.
- `scripts/random_check.py --market "Small Cap" --section debt_maturity --seed 1 --n 10 --year 2025
  --download-pdf` produced the following fixed sample: Annehem Fastigheter, Balco Group,
  G5 Entertainment, Havsfrun Investment, Infant Bacterial TherapeuticsB, INQ Group, Keo Capital,
  Orexo, Sedana Medical, and Studsvik.
- Seven candidates were skipped while filling those ten: SinterCast, Malmbergs Elektriska, BE
  Group, and Wise (HTTP 422: OCR language unavailable); Nyorda (HTTP 404: no report); HAKI Safety
  and Cinclus (plaintext HTTP 500). The latter two were recorded as `HTTP 500 non-JSON` and skipped
  without treating the failure as a sample result.
- Before any extraction output, stored result directory, or log body was opened, the ten PDFs were
  manually labelled into `eval/heldout-smallcap-2025.csv`. The blind-label commit is
  `6ed979b` (`eval: held-out Small Cap 2025 labels (blind, before any model output)`). The
  directory containing first-run results was sealed until that commit existed, then reopened only
  for scoring. No label changed after results were viewed.

## Same-label comparison — non-default `majority`

The comparison re-ran only the same ten reports with `EXTRACT_MERGE_RUNS=majority`; `merge.runs`
records sum to **14 calls** (six reports needed a second run, four were retained after one). Its
output scored **27/40 (67.5%)** values and **8/17 (47.1%)** cited pages. The same offline
breakdown is **5 empty**, **8 non-empty wrong**, and **1 page-only** miss. The only value movement
was Sedana Medical's 4697 false-positive becoming null, so it is a comparison observation rather
than a reason to alter the default. Primary plus comparison used **24 calls**, within the 40-call
budget.

Commands used for both stored snapshots (offline: no API, PDF, network, or model activity):

```powershell
python eval/run.py --labels eval/heldout-smallcap-2025.csv --stored-kb <snapshot> --no-fail
python scripts/eval_breakdown.py --labels eval/heldout-smallcap-2025.csv --stored-kb <snapshot> --section debt_maturity
```

## Small, scoped fixes encountered before measurement

- `1ed71de` — `scripts: random_check --download-pdf for fresh caches`: opt-in request body flag;
  default behavior is unchanged.
- `c669b19` — `parse: skip links whose page is not an int (HAKI Safety 500)`: a named/external
  non-integer link is skipped rather than compared to an integer page; its red regression test
  first raised the prior `TypeError`, then passed.
- `fd49f08` — `scripts: random_check tolerates plaintext errors`: an HTTP error body that is not
  JSON becomes the recorded `HTTP <code> non-JSON` skip reason instead of crashing the sample.
- `75528f4` — `scripts: eval_breakdown --labels`: adds an explicit labels CSV argument while
  retaining `eval/labels.csv` as the default; it generated both breakdowns above.

No extraction, schema, prompt, label-evaluator, or repository KB behavior was changed because of
the held-out scores. Backend parsing and random-check handling were fixed only to let the sampled
workflow record its normal skip outcomes safely.
