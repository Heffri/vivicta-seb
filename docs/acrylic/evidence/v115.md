## For the group

1. **Self-consistent wrong-scope siblings are the open scope gap** (cellavision p.84,
   net_insight p.101): tables with debt words in the body, no refuse-marker in the title,
   internal arithmetic that closes exactly — the v103/v111 guard set cannot name them, and
   in cellavision's case the identity-endorsement carried unknown labels to **full
   confidence on the wrong scope**. A "second closing table on a different page from the
   model's own note citation" rule, or entity/note identity matching, is the next general
   shape (v111's own suggestion, now with two live instances).
2. **The twin-row guard's outcome depends on whether the model cited one row or two**
   (apotea): same source on both fields → guard drops the unknown label; different quotes
   → guard never fires and the value stands. The stored answer survives because its model
   answer split the quotes. Guard-behaviour variance across identical semantic answers is
   an extract-layer question, not vocabulary.
3. **The PROMPT_BUDGET tail-drop silently truncates the candidate list for long-paged
   reports** (viaplay 2 candidates, ctt 2): the two-pass page-select can only choose from
   what survives the cut. Either the cut order (prefer higher-scored pages regardless of
   length) or a budget raise is worth one measurement round.
4. **`borrowing` singular** is a one-word keywords gap (byggmax) — trivial to add, needs
   the corpus-wide candidate-diff measurement v017 used before it ships.
